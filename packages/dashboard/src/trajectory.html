轨迹工作台

左列挑会话 → 右侧是这条会话的轮次流（从上到下按时间排）：每轮默认收起成一行摘要 （角色 + 一句话说明这条消息干了什么 + 时间/状态），点行展开该轮新增的消息卡，再点收起—— show more / show less，不被一口气灌满。每条消息只出现一次（= 它被首次追加的那一轮）， 轮内工具调用、系统提示、工具回显再折叠一层。 树结构画在左缘泳道：一个圆点 = 一轮（同一前缀的重试收进 ×N），分叉 = 同一前缀拐出不同走向。 顶栏 chips 显隐分支（主干 = 最长链，也是一条分支）；Hermes 压缩改写历史产生的续段会标「压缩续段」。
